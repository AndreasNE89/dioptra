Questions that come up first

Dioptra is empty when I open it. Is it broken?

No — that is by design. Dioptra is sandboxed and begins with access to nothing at all. On first launch it shows a welcome screen with a single button that opens the standard macOS folder picker. Whatever folder you choose becomes the part of your disk Dioptra can read, and it is remembered the next time you launch. You can add more folders at any time, and remove them just as easily.

This is deliberate. A file manager that quietly helped itself to your whole home directory would be easier to write and much harder to trust.

Why can't it open some folder I picked a while ago?

If the folder was moved, renamed, or lived on a disk that is no longer connected, the saved permission no longer points anywhere. Add the folder again from the sidebar and it will work.

Folder sizes show “—” instead of a number.

Measuring a folder means walking everything inside it, so Dioptra budgets that work rather than freezing while it counts an enormous tree. When a folder exceeds the budget it shows “—” instead of guessing. You can always measure one explicitly from its context menu, or open Space view, which maps the whole folder as rectangles sized by what they actually use.

The folder tree shows “… and N more”.

The navigation tree draws at most 400 items per folder so it stays responsive. When there are more, it says so rather than silently hiding them, and clicking that row opens the folder in the main list, which has no limit.

Dragging from Photos or Mail does nothing.

Those apps hand over a promise of a file rather than a file, and Dioptra does not accept promised files yet. Dragging from Finder, or from any app that provides a real file, works normally. This is a known gap.

Some shortcuts worth knowing

  • ⌘⇧P — jump to any folder by typing part of its name
  • ⌘⇧\ — split the tab into two panes
  • ⌥⇥ — move focus to the other pane
  • ⌘Z — undo the last file operation, including moves and deletes
  • ↩ — rename; with more than one file selected, opens batch rename

Privacy

Dioptra collects nothing and has no network access at all. The full policy is on the privacy page.
